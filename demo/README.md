# Prism Steps

Prism Steps is an original eight-bar FM tune for testing MDX playback. The lead
and one pad are on the right. The counter-melody and the other pad are on the
left. The bass and percussion are centered. Switching to mono brings all six
parts into both outputs.

Run `python3 demo/generate_demo.py` from the project directory to rebuild the
track. Copy `Prism Steps.mdx` into `~/Music/MDX Library` on the CardputerZero and
open it with Tab in MDX Player. The tune uses FM voices and needs no PDX file.

The composition, MDX file and generator in this folder are dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
